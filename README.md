# 🎂 Joyeux anniversaire Soulaymane — 11 ans

Page d'anniversaire animée (60 s, musique incluse), 100 % statique : un seul fichier `index.html`, sans dépendance ni étape de build.

## Déploiement sur Vercel
1. Sur vercel.com, **Add New → Project**, puis importer ce dépôt GitHub.
2. Laisser les réglages par défaut (Framework Preset : **Other**, pas de build command, pas d'output directory).
3. Cliquer sur **Deploy** : le lien obtenu est à envoyer à Soulaymane.

Conseil : ouvrir le lien sur téléphone, activer le son, puis toucher « ▶ Lancer la vidéo ».
